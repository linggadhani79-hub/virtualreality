# Aset mentah (belum ditanam ke aplikasi)

Unggah berkas 3D asli Anda ke folder ini (GLB, FBX, gambar, video). Berkas di sini **tidak** ikut
ke aplikasi; berkas ini bahan untuk diolah lalu ditanam ke `public/`.

## Cara unggah lewat GitHub (tanpa aplikasi tambahan)

1. Buka repo di github.com → masuk folder `aset-mentah` → **Add file → Upload files**.
2. Seret berkas ke halaman itu → **Commit changes** (langsung ke `main`).
3. Batas unggah lewat web: **25 MB per berkas**. Untuk berkas lebih besar pakai GitHub Desktop
   atau `git` (batas 100 MB per berkas).
4. Beri tahu di chat: nama berkasnya, dan mau diletakkan di mana / dipakai untuk apa
   (mis. "motor.glb, taruh di kanan mobil, bisa diklik untuk penjelasan").

Berkas di atas 100 MB tidak bisa masuk GitHub biasa; pecah atau kecilkan dulu.
