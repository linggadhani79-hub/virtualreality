Kebijakan Privasi

Smart Vocational untuk Electric Vehicle · berlaku sejak 12 November 2026

Ringkasnya: aplikasi ini tidak meminta akun, tidak mengumpulkan data pribadi, dan tidak mengirim data pemakaian Anda ke server mana pun. Semua yang disimpan berada di perangkat Anda.

1. Data yang kami kumpulkan

Tidak ada. Aplikasi berjalan tanpa login dan tanpa database. Kami tidak meminta nama, email, nomor telepon, lokasi, kontak, foto, maupun data pribadi lain.

2. Data yang disimpan di perangkat Anda

  • Berkas aplikasi dan model 3D supaya aplikasi bisa dipakai tanpa internet.
  • Pengaturan, misalnya pilihan kualitas aset.
  • Modul Ajar Digital yang ditulis pengajar di perangkat itu.

Data ini tidak keluar dari perangkat. Anda dapat menghapusnya kapan saja lewat pengaturan browser atau headset (hapus data situs / hapus data aplikasi).

3. Sensor perangkat

Sensor gerak (giroskop, akselerometer) dan pelacakan headset / controller dipakai hanya untuk menampilkan dan menggerakkan pandangan di dalam lab. Bacaan sensor diproses langsung di perangkat, tidak direkam dan tidak dikirim ke mana pun. Aplikasi tidak memakai kamera maupun mikrofon.

4. Skor dan hasil belajar

Skor tanya jawab dan hasil game merakit hanya ditampilkan di layar dan tidak disimpan atau dikirim.

5. Pihak ketiga

Aplikasi tidak memuat iklan, pelacak, maupun layanan analitik. Berkas aplikasi disajikan oleh penyedia hosting (Cloudflare). Seperti semua situs web, penyedia hosting dapat mencatat data teknis permintaan (misalnya alamat IP dan jenis browser) untuk keamanan dan kelancaran layanan; pencatatan itu tunduk pada kebijakan privasi penyedia hosting.

6. Anak dan pelajar

Aplikasi ditujukan untuk pembelajaran di sekolah / kampus vokasi di bawah bimbingan pengajar. Karena tidak ada data pribadi yang dikumpulkan, aplikasi dapat dipakai pelajar tanpa pendaftaran.

7. Perubahan kebijakan

Bila kebijakan ini berubah, tanggal di bagian atas halaman ini akan diperbarui.

8. Kontak

Pertanyaan tentang kebijakan ini dapat disampaikan kepada pengelola aplikasi di institusi Anda.
