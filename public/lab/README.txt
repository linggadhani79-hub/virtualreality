Letakkan data bawaan aplikasi di sini agar ikut terpasang dan tersedia offline di semua perangkat:

- workspaces_global.json   : isi map (dokumen "workspaces/global", bentuk { "items": [...] })
- workspaces_library.json  : pustaka aset (dokumen "workspaces/library")
- assets/<bufferId>        : berkas model 3D (GLB/FBX) dengan nama sama seperti bufferId di map

Bila folder ini kosong, aplikasi menampilkan Ruang Uji Kendaraan bawaan.
